# Player Cards Data

This directory stores player-specific card assets and editor drafts.

## Structure

- `data/player_cards/{player_id}/photos/`: Album of uploaded player photos (original and background-removed).
- `data/player_cards/{player_id}/{milestone_id}/`: Generated card PNGs and `card_editor.json` draft state for a specific match/milestone.
- `data/player_cards/.gitkeep`: Ensures the directory exists in version control.
